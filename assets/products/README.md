# Product photos

Save Design Studio photos here, one folder per product, named `<color>-<side>.jpg`:

```
assets/products/warmup-jacket/navy-front.jpg
assets/products/warmup-jacket/navy-back.jpg
assets/products/warmup-jacket/navy-lsleeve.jpg
assets/products/warmup-jacket/navy-rsleeve.jpg
```

Use `photo-setup.html` to square each photo (1200×1200) and mark its print area,
then paste the settings it gives you into `js/product-photos.js`.

Product IDs, color keys and sides are listed in `js/catalog.js`
(sides: front, back, lsleeve, rsleeve; hats only have front).

Only use photos you have the rights to: supplier images from your SanMar /
S&S Activewear account, or your own photos.
